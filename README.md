# Multiplication Trainer 1–9 × 1–5

Простой тренажёр таблицы умножения для GitHub Pages.

- первый множитель: 1–9
- второй множитель: 1–5
- 30 попыток в основном раунде
- ошибка возвращается после трёх промежуточных примеров
- если ошибка повторяется, пример снова откладывается на три примера
- поздние ошибки дорабатываются после 30-й попытки
- статистика сохраняется локально в браузере (`localStorage`)
- работает без сервера и зависимостей

## GitHub Pages

Положите `index.html` в корень публичного репозитория и включите Pages: **Settings → Pages → Deploy from a branch → main / root**.
